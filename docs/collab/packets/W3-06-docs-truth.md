# W3-06 Docs truth: ledger, status, review trail

Depends on: nothing   Parallel-safe with: every code packet (docs only)

## Goal
Every claim in the repository's documentation is true of the code as it stands, and a reader can tell what is
built, what is planned, and what was decided, without reading the git log.

## Context (verified)
1. `docs/collab/LEDGER.md` carries the packet table, the Grok usage log, the live-evidence log, the open
   decisions and the known limits. Several rows describe work that has since landed or changed hands.
2. `docs/collab/ROADMAP.md` lists waves 3 to 6; wave 3's table predates UX-00 through UX-02a and the
   TEST-02/TEST-03 split.
3. `README.md` has Install / Usage / Configure / Remove / Development / Security sections that the publishing
   checklist in `docs/collab/PUBLISHING.md` requires to stay current; the CLI gained `notify` and `open`.
4. `docs/collab/reviews/SECURITY-REVIEW-2026-09-05.md` lists S1 to S12 with a "Fix in" column; some of those
   packets have landed and the column now lies about the state of the tree.
5. The Grok collaboration is over: the Owner ended it on 2026-09-06 after the headless client repeatedly
   ended runs on text-only turns. `AGENTS.md`, `PROTOCOL.md` and the ledger still describe a two-agent flow.

## Changes
- **LEDGER.md**: packet table reflects reality (UX-00, UX-01, UX-02a, W3-01, W3-02, TEST-02, TEST-03, D-008);
  the Grok usage log gets a closing row stating the collaboration ended and why; the decisions table shows
  D-003 (Apache-2.0) and D-008 (risk bar) as decided, and lists what is still open.
- **ROADMAP.md**: wave 3 shows the UX wave and the test packets; each row says landed / in progress / planned.
- **README.md**: Usage documents `sentinel-action notify` and `sentinel-action <id> open [--logs]`; Configure
  documents the `[notify]` block; Security points at the review, the SkillSpector self-scan and the baseline.
- **SECURITY-REVIEW-2026-09-05.md**: add a "Status" column, marking S3, S6, S7 and S8 as fixed by W3-02 and
  S5 as fixed by UX-00, with the commit that did it. Do not restate a finding as fixed without checking.
- **AGENTS.md / PROTOCOL.md**: describe the current workflow (a Chief plus Claude subagent squads per packet),
  keeping the packet, report, ask and ledger contract intact.
- Add `docs/collab/STATUS.md`: one page, regenerated by hand at the end of a wave — what works today, what is
  live on the Owner's machine, what is next, and the current test count.

## Tests
No unit tests. Verification is a fact-check: every claim changed must be checked against the code or a
commit, and the report records how each was checked.

```
.venv/bin/pytest -q          # unchanged, still green: this packet must not touch code

```

Editing anything outside documentation; inventing a status for work not in the tree; deleting historical
ledger rows (correct them in place with a dated note); editing tests/joint/.
